Overview of the ELK Stack

The ELK Stack is a set of powerful open-source tools designed for searching, analyzing, and
visualizing large volumes of data in real-time. The three core components of the stack are:


[ Data Sources ]  ──>  [ Logstash ]  ──>  [ Elasticsearch ]  ──>  [ Kibana ]
(Apps, Servers,        (Ingest, Parse,      (Index, Store,        (Dashboards,
 Network Devices)       & Transform)         Query & Search)       Visual Charts)

1. Logstash – A data collection and transformation pipeline. form Application, servers, network devices. 

Parsing logs - "Parsing logs" refers to the process of analyzing and extracting meaningful
information from log files. Log files are records generated by software applications, systems,
or servers that track events, processes, and activities, usually for debugging, monitoring, or
auditing purposes.

Identify Logs: Plain Text, JSON, XML, CSV, 

Extract logs : 

Timestamp
Log Level (INFO, WARN, ERROR)
IP Address
Username
Request URL
Status Code
Error Message

3. Analyzing logs: After parsing, you can search or analyze the logs for specific issues,
performance bottlenecks, or security breaches.

2. Elasticsearch – A distributed search and analytics engine.

Index = A book : An Index is a logical collection of related documents in Elasticsearch

Shard = Chapters of the book : A Shard is a physical partition (piece) of an index. Instead of storing the complete index on one server, Elasticsearch divides the index into smaller parts called

Replica = A photocopy of the chapters, A Replica is an exact copy of a Primary Shard.

3. Kibana – A visualization and data exploration tool. : Kibana is the web-based graphical user interface (GUI) for Elasticsearch. It allows users to search, analyze, visualize, and monitor the data stored in Elasticsearch without writing complex queries.
